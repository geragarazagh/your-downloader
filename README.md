# Your Downloader

Downloads video, audio, subtitles and comments from YouTube and other sites with yt-dlp.

## Install

Terminal agents:

```sh
npx skills add geragarazagh/your-downloader -g
```

Claude Code:

```sh
claude plugin marketplace add geragarazagh/your-downloader
claude plugin install your-downloader@your-downloader
```

Gemini CLI:

```sh
gemini extensions install https://github.com/geragarazagh/your-downloader
```

Any other agent: paste the text of [`SKILL.md`](skills/your-downloader/SKILL.md) into its instructions.
